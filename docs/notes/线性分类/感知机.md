本篇主要探讨一下线性分类的主要思路和其中较为简单的感知机模型

线性分类实际上就是通过对特征的线性组合完成对样本的分类，那么这里就存在一个映射，我们最终希望将一个 $p$ 维的特征向量映射为一个类别，那么怎样表示这个类别呢？我们有硬分类和软分类两种方法：
- 硬分类就是用一个数字表示类别，以二分类为例输出就是 $\{0, 1\}$
- 软分类就是计算出该样本属于每一个类别的概率，也就是映射成一个概率向量
  
进一步，如果我们对多分类问题采取硬分类，也有两种思路：

*   **多类线性判别**：为每一个类别 $k$ 都学习一套独立的参数 $(w_k, b_k)$。对于输入的特征向量 $x$，我们计算它在每一个类别下的得分 $z_k = w_k^T x + b_k$，最终预测的类别就是得分最高的那个。其数学表达式为：
    $$\hat{y} = \argmax_{k \in \{1, \dots, K\}} (w_k^T x + b_k)$$
    这种方法的几何意义是将空间划分为 $K$ 个凸多面体区域。

*   **二分类策略组合**：将多分类问题拆解为多个二分类子问题。常见的有两种具体策略：
    *   **一对其余（OvR）**：训练 $K$ 个分类器，每个分类器负责区分“属于类别 $i$”和“不属于类别 $i$”。预测时，选择输出置信度最大的那个类别。
    *   **一对一（OvO）**：在任意两个类别之间都训练一个分类器（共需 $\frac{K(K-1)}{2}$ 个分类器）。预测时，让所有分类器进行投票，得票数最多的类别即为最终结果。

---

在上述线性硬分类的思路中，最典型的模型便是**感知机**。它采用了最简单的二分类硬判别函数，即利用符号函数 $\text{sign}(z)$ 将线性组合的结果映射到 $\{-1, +1\}$。感知机的核心在于其“错误驱动”的学习算法：只有当模型对样本分类错误时，才利用梯度下降更新参数。这种设计使得感知机在数据线性可分的情况下具有确定的收敛性质（[Novikoff 定理](https://math.stackexchange.com/questions/2183227/novikoff-s-proof-for-perceptron-convergence)）

下面我们给出感知机模型：
- 要求：数据样本线性可分
- 输入： $X \in \mathbb{R}^p$
- 参数： $w \in \mathbb{R}^p, b \in \mathbb{R}$
- 输出： $\hat{y} = \text{sign} (w^T X + b)$
- **训练过程**：
  - 损失函数：$$L(w) = \sum_{i = 1}^{N} (w^T x_i + b) y_i$$

很幸运的是，在利用随机梯度下降训练感知机模型时我们有确定的收敛保证，也就是 **Novikoff 定理**，下面我们给一个证明：

---

假设训练数据集 $T$ 线性可分，令增广特征向量为 $\hat{x} = (x^T, 1)^T$，增广权重为 $\hat{w} = (w^T, b)^T$。
1. **存在性**：存在单位向量 $\|\hat{w}_{opt}\| = 1$ 及间隔 $\gamma > 0$，使得对所有样本均有 $y_i(\hat{w}_{opt} \cdot \hat{x}_i) \geq \gamma$。
2. **有界性**：存在 $R > 0$，使得对所有样本均有 $\|\hat{x}_i\| \leq R$。

**结论**：
若从 $\hat{w}_0 = 0$ 开始，感知机算法在误分类时执行更新 $\hat{w}_k = \hat{w}_{k-1} + y_i \hat{x}_i$，则发生误分类更新的次数 $k$ 满足：
$$k \leq \left( \frac{R}{\gamma} \right)^2$$



**证明：**

通过对更新 $k$ 次后的权重模长 $\|\hat{w}_k\|^2$ 建立**下界**和**上界**：

**1. 建立下界（利用投影）：**
将更新公式两边点乘理想方向 $\hat{w}_{opt}$：
$$\hat{w}_k \cdot \hat{w}_{opt} = \hat{w}_{k-1} \cdot \hat{w}_{opt} + y_i(\hat{w}_{opt} \cdot \hat{x}_i)$$
根据条件1（存在性）：$y_i(\hat{w}_{opt} \cdot \hat{x}_i) \geq \gamma$，递推可得：
$$\hat{w}_k \cdot \hat{w}_{opt} \geq k\gamma$$
由 Cauchy-Schwarz 不等式 $\hat{w}_k \cdot \hat{w}_{opt} \leq \|\hat{w}_k\| \|\hat{w}_{opt}\|$ 且 $\|\hat{w}_{opt}\|=1$：
$$\|\hat{w}_k\| \geq k\gamma \implies \|\hat{w}_k\|^2 \geq k^2\gamma^2 \quad \dots \text{(1)}$$

**2. 建立上界（利用误分类条件）：**
计算 $\hat{w}_k$ 的平方模：
$$\|\hat{w}_k\|^2 = \|\hat{w}_{k-1} + y_i \hat{x}_i\|^2 = \|\hat{w}_{k-1}\|^2 + 2y_i(\hat{w}_{k-1} \cdot \hat{x}_i) + \|\hat{x}_i\|^2$$
由于该次更新由误分类触发，满足 $y_i(\hat{w}_{k-1} \cdot \hat{x}_i) \leq 0$，结合条件2（有界性）：
$$\|\hat{w}_k\|^2 \leq \|\hat{w}_{k-1}\|^2 + R^2$$
递推可得：
$$\|\hat{w}_k\|^2 \leq kR^2 \quad \dots \text{(2)}$$

结合不等式 (1) 与 (2)：
$$k^2 \gamma^2 \leq \|\hat{w}_k\|^2 \leq kR^2$$
$$k^2 \gamma^2 \leq kR^2 \implies k \leq \left( \frac{R}{\gamma} \right)^2$$

误分类更新次数 $k$ 存在有限上界，因此感知机算法必在有限s步内收敛。 $\square$

---

以上就是感知机模型的主要内容，可以发现感知机模型的一个重要前提是样本是线性可分的，而对于更复杂的样本分布还有一种在此基础上稍作改进的**口袋算法（pocket algorithm）**，它的思路类似于贪心算法，就是每次迭代都去判断更新后的 $w$ 是否是最优的，这可以保证我们一定能找到试过的参数中最好的，但代价是显著增大了计算的开销，训练效率降低。

```py
def pocket(training_list, max_iteration):
    w = randomVector()
    best_error = error(w)
    for i in range(0, max_iteration):
        x=misclassified_sample(w, training_list)  
        w=vector_sum(w, x.y(x))
        if error(w) < best_error :
            best_w = w
            best_error = error(w)
    return best_w
```
